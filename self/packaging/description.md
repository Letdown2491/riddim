riddim is a minimal Spotify player for Linux: search tracks and playlists,
play with queue, history, and radio, browse artist and album pages, and pin
playlists to the sidebar. Native, responsive, and typically around 120 MB of
RAM.

Playback runs on Soloist, Spotify's official headless player, which riddim
downloads and keeps updated; Now Playing and media keys go through MPRIS,
and state persists between sessions.

Requires Spotify Premium and a one-time setup: creating your own Spotify
developer app for the library connection, then pairing the riddim playback
device from any Spotify app you already use. riddim walks you through both
on first launch.

riddim is a Linux port of Cadence by Miho, a Spotify player for macOS; same
engine, same design, with riddim's own mark and interface icons.
